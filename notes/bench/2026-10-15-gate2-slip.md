# Gate 2 — Slip on the unit (2026-10-15, evening)

Unit: Blackbox Mk1 (STM32H743 rev V), firmware **37.1.0d** (JOEBOX 1 full set + the restart-loop fix + Slip, dev
build, no `BBEXTRA.BIN`), power jack on mgr-ran's USB. Thomas at the unit; measurements by `bench/bbusb.py` over the
USB audio (Outs 1–3, 24-bit / 48 kHz) and the dev build's peek.

Setup: internal clock 120 BPM, metronome on Out 2 (it reaches the USB capture only once Metro Out is set to Out 2 —
the first takes had it on the headphones), a 1-bar factory drum loop on a Clip pad, Loop On, Quant 1 bar, Sync 1/4,
output Out 1. At 120 BPM one tick = 25 samples. Reference take at Slip `+0.000`; each later take aligned on its own
first *whole* click and cross-correlated against the reference on Out 1 (`bbusb.py shift`; a click 96 samples into a
take had skewed the first reading by 16 samples, so the tool now skips a click in the first 1 000).

| check | result |
|---|---|
| 1. reference, Slip 0 | sounds as before the mod; metronome grid 24 000 samples apart, 0 jitter |
| 2. Slip `+0.060` (D-014 sign) | **+1 500 samples** (+60.00 ticks), exact |
| 3. Slip `−0.120` | **−3 000 samples** (−120.00 ticks), exact |
| 4. by ear | `+0.480` falls between the clicks; `+1.000` puts the accent on beat 2 |
| 5. live change | no click, smooth (Thomas); over a 30 s sweep of dozens of values Out 1's RMS stayed 0.0066–0.0068 and no run of digital silence > 2 ms |
| 6. knob | slow = single ticks, fast = hundreds of ticks per 50 ms — "tricky, especially to set back to 0" |
| 7. save / power-cycle / reload | `+0.120` kept and heard |
| 8. load, faults | Tools `!11/15%` (the `!` = no bank 2 payload, expected), no fault or watchdog record |

Pass. Two changes came straight out of it, same evening (37.1.1, emulation-tested, the feel still to be checked on the
unit):

- **Sign, D-016**: Thomas wants the CDJ jog's feel — counter-clockwise slows the record down (behind the beat),
  clockwise pushes it ahead. So the row reads `+` = ahead, `−` = behind (D-014's `+` = later is reversed); the
  measurements above were taken under D-014, so under 37.1.1 the same knob positions read with the opposite sign.
- **Knob**: single ticks slow, one 1/64 (60 ticks) per turn event when fast, snapped to the 1/64 grid, and a turn that
  reaches 0 stops there (a pause of ¼ s or the other direction moves on).

Also seen: the browser's pre-listen sounded choppy while looking for a loop (not yet compared with stock 3.1.9 / 37.0.2d;
the load readout was low, 11/15 %).
