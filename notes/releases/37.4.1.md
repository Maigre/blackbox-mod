# blackbox-mod 37.4.1

Thomas's fork ([Maigre/blackbox-mod](https://github.com/Maigre/blackbox-mod)) of JOEBOX 1, the unofficial feature
mod for the **original 1010music Blackbox** (Mk1) on stock firmware **3.1.9**. This is **37.4.0 with the fixes from
Gate 3b part 4**: a take loaded into a playing Clip pad starts on its own window, Fit gets an Auto that rounds to bars,
and the Clip Waveform's view follows the marker you turn. TOOLS shows `37.4.1`.

**Status: a test release.** Every part passes the emulated suites (`./check.sh`: 31 suites, 0 failed). None of it has run on a
unit yet.

## New since 37.4.0

- **A take loaded into a playing Clip pad plays its own window** (F-p). After a Sync or Quant change, a file loaded
  under a playing pad kept the old file's window: the audio repeated the old period and drifted off the metronome
  until the pad was stopped and started again. The cause is stock's: a Sync set while the browser has the slot closed
  puts the pad on a step built for no file, and nothing rebuilds it once the new file opens. The pad's own Sync is now
  sent once more right after the open, only when its last step came from the closed slot. The new take's first loop
  point can come a little off its 2-bar grid, then every pass is on it (as a Region change already does). An ordinary
  switch to a shorter take plays as stock plays it.
- **Fit has two Autos** (D-031). The list is now `Off, Auto (Bars), 1/4, 1/2, 3 beats, 1 bar, 6 beats, 2, 4, 8 bars,
  Auto (Beats)`. **Auto (Bars)** fits the loop to whole bars so it stays in step with the metronome: under a bar the
  nearest of 1/4, 1/2 or 1 bar, from a bar up the nearest whole number of bars. **Auto (Beats)** is 37.4.0's Auto, the
  nearest whole number of beats (for odd lengths and polyrhythms).
- **The Clip Waveform's view goes to the marker you move.** A Loop Start (TL) or Loop End (TR) turn takes the overview
  to the edge it moves; after a pause with no turn the view follows the playhead again.
- **Less memory taken without the second file** (D-030). The boot's SDRAM block takes Prism's and the insert
  effects' part only when this build's `BBEXTRA.BIN` is in bank 2. A paired unit allocates exactly what 37.4.0 did; a
  unit without a usable second file keeps 493 568 B more for presets.

The second file, `BBEXTRA.BIN`, changes with this release (the Clip Window's bank 2 code changed).

## Install

As 37.4.0 (`notes/releases/37.4.0.md` §Install), with this release's two files and `blackbox-mod-37.4.1.json`:
both files from the same build to the root of the card, BACK + INFO at power-on on the normal power supply. The first
boot **restarts itself once** (bank 2 is rewritten from the new `BBEXTRA.BIN`); TOOLS then shows **`37.4.1`** with
**no `!`**.

## Presets saved on Fit Auto

A preset keeps Fit as its place in the list, so the lengths load as saved and **a pad saved on Auto loads as Auto
(Bars)**. A take whose length is not a whole number of bars then plays fitted to bars (a 14-beat take as 4 bars). Set
that pad to Auto (Beats) to get 37.4.0's count back, and save.

## Known issues

- **The analog outputs crunch late in a long sitting, seen twice** (F-o, 2026-10-20, 37.4.0d): every analog output
  (phones, Out 1, Out 2) grows into a hard bit-reduced sound while the USB capture of the same outputs stays clean; a
  power cycle cures it. The unit was on a computer's USB power at the time; the next sittings go through a
  self-powered hub to tell power from firmware. `notes/bench/2026-10-20-gate3b-part4.md` §F-o.
- **A pad silent after a preset load or a boot, seen four times** (F-n, 2026-10-19/20, 37.4.0d, always the same pad
  and file): the pad plays a first chunk or nothing; loading the file again cures it. Not reproduced on demand yet.
  `notes/bench/2026-10-19-gate3b-part2.md`, `-20-gate3b-part3.md`, `-20-gate3b-part4.md`.
- 37.4.0's known issues all still apply: `notes/releases/37.4.0.md`.
