# blackbox-mod 37.3.1

Thomas's fork ([Maigre/blackbox-mod](https://github.com/Maigre/blackbox-mod)) of JOEBOX 1, the unofficial feature
mod for the **original 1010music Blackbox** (Mk1) on stock firmware **3.1.9**. Everything 37.3.0 has is still there
(Slip, Region, Loop Len, Fit and Loop Fade on Clip pads, the knobs on a Clip pad's waveform, the Slip knob, the
restart-loop fix and the rest of JOEBOX 1). This release makes the waveform screen's four corner knobs readable,
puts the playhead line on the frame you hear, and makes Loop Len wait a little longer before it takes a value.
TOOLS shows `37.3.1`.

**Status: a test release.** Every part passes the emulated suites (`./check.sh`: 31 suites, 0 failed). None of it
has run on a unit yet; it answers what the second test session (Gate 3b, on 37.3.0d) found so far.

## New since 37.3.0

- **Readable waveform knobs.** On every pad's waveform screen, whatever its mode (Sample, Clip, Slicer, Granular,
  New Rec, New Multi), the four corner knobs' text is white with a thin black edge instead of stock's grey. Stock's
  grey read about 3:1 over the waveform's light blue and over the dark background; the edged white reads 12:1 or
  better on both. The font, its size and the knobs' names are the same as before.
- **The playhead line shows what you hear.** On a Clip pad playing a Region, with Slip, with Loop Len on or with Fit,
  the line on the waveform now sits on the frame that is playing: it starts at the loop bracket's left edge and wraps
  at its right edge, leads or trails by the Slip, loops inside Loop Len's window. Before, it showed stock's count from
  the start of the file: on a loop starting 6 072 frames in, it ran that far behind the audio and wrapped early.
- **Loop Len waits for the knob to rest.** A value is taken about 0.3 s after the knob stops on it (it was about
  0.2 s). An ordinary turn from Off to 1/4 no longer engages the 1/8 it passes on the way; stepped through slowly,
  resting on each value, it still takes each in turn. Off is still immediate.

The second file, `BBEXTRA.BIN`, changes with this release (the playhead and Loop Len's timing run from the chip's
second flash bank).

## Install

1. You need **two files from the same build**: `BLACKBOX.bin` and `BBEXTRA.BIN`. Patched firmware images are not
   distributed. Make them from your own copy of 1010music's stock 3.1.9 `BLACKBOX.bin` (from
   <https://1010music.com/downloads>), either with the release's patch file, `python3 apply.py BLACKBOX.bin
   blackbox-mod-37.3.1.json` (it checks the stock file and the result by SHA-256 and writes both files), or from
   source: `RELEASE=1 ./build.sh && python3 patch.py solo slice duck chord cond filter cpu od comp seqfix fx2 munchi
   master fault cave` gives `out/<sets>/BLACKBOX.bin` and `out/BBEXTRA.BIN`.
2. Keep the stock `BLACKBOX.bin` somewhere safe: it is your way back.
3. Copy **both** files to the root of the microSD card, over the old ones if they are there.
4. With the Blackbox on its normal power supply, hold BACK + INFO while powering on, and let go when the install
   screen shows.
5. The first boot **restarts itself once**, a second or two in: that is the second file being written to the chip's
   second flash bank. It does so on a unit that ran 37.3.0 or earlier too, since their second file is not this one.
   Leave the card in and the power on until it is back up.
6. TOOLS shows **`37.3.1`**, with **no `!`** in front of the load figures.

A `!` means the second file is missing or from another build: Prism, Confetti, the insert effects, Slip, Region,
Loop Len, Fit and Loop Fade are then off, the waveform knobs are stock's grey and the playhead line is stock's
(everything else works). Put the
`BBEXTRA.BIN` that belongs with your `BLACKBOX.bin` on the card and power off and on.

## Back to stock

Put 1010music's stock 3.1.9 `BLACKBOX.bin` on the card and install it the same way (BACK + INFO at power-on). The
second flash bank keeps this build's code, unused: stock firmware never looks at it, and it does not touch the unit's
calibration.

## Known issues

- **Not yet run on a unit**: everything new in this release (see Status).
- At a step change the playhead line can show, for an instant, where the step that is fading out was reading (stock
  does the same); in Loop Len's window that is just past the window's end.
- Loop Len: a quick turn that overshoots and rests on the wrong value for more than about 0.3 s before you turn back
  still takes it.
- A line on the waveform screen that is longer than its knob's box already ran past it on the left on stock (Sample
  mode's `LpEnd:` from 1 000 000 frames on); its edge goes one pixel further.
- Each knob's text now takes nine of stock's text draws instead of one, in the screen's task (not the audio's).
- 37.3.0's known issues all still apply: `notes/releases/37.3.0.md`.

## Images (built locally; not in git)

Built 2026-10-17 with Arm GNU 14.2 from the commit that sets `src/release.h` to 37.3.1, on branch `halo` (cut from
`37loop/blackbox-t-021` at 37.3.0), full set `solo slice duck chord cond filter cpu od comp seqfix fx2 munchi master
fault cave`, with `BANK2_NEW=1` (bank 2's code changed since 37.3.0). Bank-2 payload: id `0xce1ead5b`, length `0x4180`,
sum `0xc6b2bdbc`, byte for byte the same in both builds; each `BLACKBOX.bin` carries that id and sum and lets the card
loader write bank 2. Bank 1 (`.cave`): 57 040 of 57 736 B in the release build, 57 160 in the dev build;
`.bank2` 16 724 B.

anywhere in the machine.
